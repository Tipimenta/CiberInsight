# Contribuindo com o CyberInsight

Contribuições de código, documentação e correções são bem-vindas.

Antes de enviar uma alteração:

1. não inclua dados reais de pacientes, clínicas, servidores, credenciais ou backups de avaliações;
2. preserve a separação entre regras metodológicas do instrumento e recursos de interface;
3. execute `npm run validate:instrument`;
4. execute `npm run build` quando as dependências estiverem instaladas;
5. descreva claramente o que foi alterado e por quê.

Alterações nas perguntas, critérios de níveis, scoring ou regra de NS/NA devem ser tratadas como mudanças metodológicas e não apenas como ajustes de software.
